BREAKSUITE6 RIFTBOUND LIBRARY — OFFICIAL CARD GALLERY SYNC

Registered products
1. Riftbound: League of Legends TCG — Origins Booster 6-Box Case (OGN)
2. Riftbound: League of Legends TCG — Origins - Proving Grounds (OGS)
3. Riftbound: League of Legends TCG — Spiritforged Booster 6-Box Case (SFD)
4. Riftbound: League of Legends TCG — Unleashed Booster 6-Box Case (UNL)
5. Riftbound: League of Legends TCG — Vendetta Booster 6-Box Case (VEN)

What this update adds
- A separate Riftbound catalog inside the existing BreakSuite6 database.
- Game and set filters that preserve the existing One Piece library.
- Exact-printing identities for base, Alternate Art, Overnumbered, Signature,
  and other treatments supplied by official Riot data.
- A one-click sync from the public official Riftbound Card Gallery data feed.
- A JSON backup importer for recovery.
- Local caching for images hosted on Riot-controlled domains only.

How to populate the cards
1. Open BreakSuite6 > Import Manager.
2. Under Riftbound Library, click Sync Official Gallery.
3. Wait while the official card records and Riot-hosted images are saved.
4. Open Riftbound Library to browse OGN, OGS, SFD, UNL, and VEN.

The importer accepts either a top-level JSON array or an object containing a
cards, items, results, data, or content array. Records from unsupported sets
are ignored instead of being mixed into the registered Riftbound libraries.

This update does not erase the One Piece catalog, saved cards, Break Board,
Buyer Bags, overlays, connector assignments, or order history.
